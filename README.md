# Еда без паники — сайт для GitHub Pages

Статическая версия сайта для проекта о здоровом питании студентов ТОГУ. Работает без Python и сборки: `index.html`, `style.css`, `script.js`.

## Опубликовать через GitHub Pages
1. Создай новый репозиторий на GitHub.
2. Загрузи в корень репозитория три файла: `index.html`, `style.css`, `script.js`.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. В качестве branch выбери `main`, папку `/ (root)` и нажми **Save**.
6. Подожди пару минут — GitHub покажет адрес опубликованного сайта в разделе Pages.

## Что работает
- адаптивный лендинг;
- фильтры рецептов и сохранение избранного;
- список покупок с локальным сохранением;
- справочник состояний здоровья;
- интерактивный тест;
- локальная доска обсуждений.

## Важное ограничение GitHub Pages
GitHub Pages — статический хостинг, поэтому эта версия не имеет серверной базы данных. Посещения, список покупок и сообщения сохраняются только в браузере конкретного посетителя. Локальный счётчик не является общим счётчиком уникальных пользователей. Для общего форума, реальной статистики и общей базы данных подключи backend или облачный сервис (например, Supabase/Firebase) и настрой правила доступа.

Медицинские карточки предназначены для общего ознакомления и не заменяют диагностику или рекомендации врача.
